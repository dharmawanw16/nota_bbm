Kebijakan Privasi NotaBBM

Terakhir diperbarui: 27 Oktober 2026

Kebijakan ini menjelaskan bagaimana Karya Tunggal Apps menangani informasi saat Anda menggunakan NotaBBM.

Data yang disimpan aplikasi

NotaBBM tidak mewajibkan akun. Data transaksi dan pengaturan seperti jenis dan jumlah BBM, total pembayaran, nomor polisi jika diisi, waktu transaksi, data SPBU, nama operator, serta preferensi nota disimpan di database lokal pada perangkat. NotaBBM tidak mengirim isi data tersebut ke server milik pengembang.

Berbagi file dan pencetakan

Jika Anda memilih membagikan nota, aplikasi membuat file PDF atau JPG dan menyerahkannya ke aplikasi tujuan yang Anda pilih. Aplikasi tujuan kemudian menangani file tersebut sesuai kebijakannya. Jika Anda mencetak, data nota dikirim melalui Bluetooth ke printer yang Anda pilih.

Penyimpanan dan penghapusan

Data lokal tersimpan sampai Anda menghapus data aplikasi melalui pengaturan Android atau menghapus aplikasi. File yang sudah dibagikan atau disimpan di luar NotaBBM perlu dihapus dari lokasi atau aplikasi tujuan secara terpisah.

Perubahan kebijakan

Kebijakan ini dapat diperbarui jika fitur atau praktik pemrosesan data berubah. Versi terbaru akan tersedia di halaman kebijakan privasi publik.
